## CLI reference

The pages below are generated from the `clap` command definitions by `cargo xtask doc-gen cli`.
Do not edit them by hand: any manual edit will be overwritten the next time the generator runs.

To regenerate locally:

```sh
cargo xtask doc-gen cli
```

To verify that the checked-in reference is up to date (used in CI):

```sh
cargo xtask doc-gen cli --check
```
